# Frontend (WearableApp)

La UI de la app del reloj no vive en esta carpeta: es el proyecto nativo de
Android Studio ubicado en `../app` (Kotlin + Jetpack Compose para Wear OS),
con `../settings.gradle.kts` como raíz del proyecto Gradle.

Esta carpeta se conserva vacía por compatibilidad con la estructura sugerida
del proyecto integrador. Ver `../architecture_wearable.md` para el detalle
completo.
